# Кастомизация командной строки Windows (CMD)

Утилита для настройки классической консоли Windows через `HKCU:\Console`: три цветовые схемы, шрифты, курсор и непрозрачность. Работает на Windows 10/11 с PowerShell 5.1 или 7+, без прав администратора.

## Быстрый запуск

Дважды щёлкните `Customize-Cmd.cmd` или выполните в папке проекта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Customize-Cmd.ps1
```

Разрешение запуска действует только для этого процесса. Постоянная политика выполнения не меняется.

Интерактивное меню:

| Пункт | Действие |
| --- | --- |
| 1–3 | Matrix, Dracula, Retro Amber |
| 4–6 | Consolas 18 px, Lucida Console 16 px, Cascadia Code 18 px |
| 7–8 | Тонкий или полный курсор |
| 9 | Непрозрачность 30–100% |
| 0 | Удалить переопределения оформления (с подтверждением) |
| R | Восстановить исходные параметры |
| S | Показать сохранённые параметры |
| Q | Выход |

Неверный ввод не закрывает меню. Перед применением шрифта проверяется его наличие в системе.

## Запуск через параметры

```powershell
# Посмотреть, что будет изменено, без записи в реестр и создания копии
.\Customize-Cmd.ps1 -Action Apply -Theme Dracula -Opacity 90 -WhatIf

# Применить тему, шрифт и курсор одной командой
.\Customize-Cmd.ps1 -Action Apply -Theme Dracula -Font Consolas -FontSize 20 -Cursor Small -Opacity 90

# Изменить только непрозрачность
.\Customize-Cmd.ps1 -Action Apply -Opacity 85

# Показать управляемые параметры реестра
.\Customize-Cmd.ps1 -Action Status

# Восстановить параметры, сохранённые перед первым изменением
.\Customize-Cmd.ps1 -Action Restore

# Удалить управляемые переопределения оформления
.\Customize-Cmd.ps1 -Action Reset -Confirm
```

Если политика выполнения блокирует эти команды, используйте префикс `powershell.exe -NoProfile -ExecutionPolicy Bypass -File` перед путём скрипта, как в примере быстрого запуска.

| Параметр | Значения |
| --- | --- |
| `Action` | `Menu` (по умолчанию), `Apply`, `Status`, `Restore`, `Reset` |
| `Theme` | `Matrix`, `Dracula`, `RetroAmber` |
| `Font` | `Consolas`, `Lucida Console`, `Cascadia Code` |
| `FontSize` | 8–72 **пикселя**, по умолчанию 18; требует `Font` |
| `Cursor` | `Small` (25%), `Full` (100%) |
| `Opacity` | Целое число 30–100; 100 — полностью непрозрачное окно |
| `BackupPath` | Путь к резервной копии; по умолчанию `backups\original-console.json` рядом со скриптом |
| `WhatIf` | Предварительный просмотр без изменений |
| `Confirm` | Запрос подтверждения перед записью |

Параметры оформления используются только с `-Action Apply`. Без `Theme`, `Font`, `Cursor` или `Opacity` действие `Apply` завершится с ошибкой. Неуказанные параметры оформления не меняются.

## Резервная копия, восстановление и сброс

Перед первым `Apply` или `Reset` автоматически создаётся JSON-копия управляемых значений с их типами. Копия не перезаписывается при последующих изменениях. Если сохранить или проверить копию не удалось, изменение настроек не начинается. Папка `backups/` исключена из Git.

`Restore` возвращает исходные значения; параметры, отсутствовавшие до первого изменения, удаляются. Содержимое копии проверяется до записи. Отсутствующая или повреждённая копия вызывает ошибку без изменения реестра.

`Reset` удаляет только 16 цветов, цвета текста и всплывающих окон, имя/размер/семейство/насыщенность шрифта, размер/тип курсора и непрозрачность. Другие параметры и вложенные ветки сохраняются. Это удаление переопределений, а не обещание конкретного «заводского» оформления: итог зависит от Windows и настроек приложения.

Копия привязана к этой ветке реестра, но не к компьютеру или пользователю: храните её вместе с соответствующей установкой. Чтобы создать новую исходную точку, сначала восстановите нужные настройки и перенесите старый файл копии в другое место. Для собственного пути передавайте одинаковый `-BackupPath` при изменении и восстановлении:

```powershell
.\Customize-Cmd.ps1 -Action Apply -Theme Matrix -BackupPath .\my-console.json
.\Customize-Cmd.ps1 -Action Restore -BackupPath .\my-console.json
```

Несколько операций записи в реестр не являются транзакцией. При ошибке доступа после частичного применения устраните причину и выполните `Restore` из сохранённой копии.

## Где виден результат

Откройте **новое** окно классической консоли (`Console Host`). Утилита сохраняет настройки для новых окон, а не меняет текущее окно.

`HKCU:\Console` содержит общие настройки Console Host: они могут затрагивать и другие консольные приложения. Настройки конкретного приложения и ярлыка могут иметь приоритет. Windows Terminal использует собственные профили, поэтому запуск `cmd.exe` внутри Terminal может не показать эти изменения.

Формат цветов исправлен на `COLORREF` (`0x00BBGGRR`). Размер шрифта указывается в пикселях, а не в пунктах. Основание: [документация Microsoft о COLORREF](https://learn.microsoft.com/en-us/windows/win32/gdi/colorref) и [описание настроек Console Host](https://github.com/microsoft/terminal/blob/main/doc/ConsoleHostSettings.md).

## Проверки

Внешние модули не нужны:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\Smoke.Tests.ps1
pwsh.exe -NoProfile -File .\tests\Smoke.Tests.ps1
```

Проверяются цветовые схемы, границы непрозрачности, валидация параметров, режим `WhatIf`, сохранение первой копии, восстановление, сброс, обработка повреждённой копии и сохранение посторонних значений/веток. Запись выполняется в уникальную временную ветку `HKCU:\Software\WinCmdCustomizerTests\<GUID>`, которая удаляется после проверки. Реальная ветка `HKCU:\Console` не изменяется. PowerShell-файлы сохранены в UTF-8 с BOM для корректного русского текста в Windows PowerShell 5.1.
