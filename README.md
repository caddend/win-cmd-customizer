# Кастомизация командной строки Windows (CMD)

Скрипт для настройки внешнего вида классической командной строки (`cmd.exe`) через ветку реестра текущего пользователя `HKCU:\Console`. Позволяет переключать цветовые схемы, менять шрифты, размер курсора, прозрачность окна и быстро возвращаться к стандартным параметрам Windows.

---

## Требования

- Windows 10 или Windows 11
- PowerShell 5.1 или PowerShell 7+
- Права администратора **не требуются** (все изменения пишутся только в `HKEY_CURRENT_USER`)

---

## Подготовка и запуск

По умолчанию в PowerShell может быть включена блокировка сторонних скриптов. Разрешите запуск для текущего процесса и запустите скрипт:

```powershell
# 1. Перейдите в папку со скриптом
Set-Location -Path "C:\путь\к\папке"

# 2. Разрешите запуск неподписанных скриптов для текущей сессии
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# 3. Запустите скрипт
.\Customize-Cmd.ps1
```

Либо запустите скрипт одной командой без предварительного открытия PowerShell:

```cmd
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Customize-Cmd.ps1
```

---

## Доступные пресеты и возможности

После запуска отобразится текстовое интерактивное меню:

1. **Цветовые схемы**:
   - `1` — **Matrix**: неоново-зеленый текст на черном фоне.
   - `2` — **Dracula**: современная темно-фиолетовая тема со сбалансированным контрастом.
   - `3` — **Retro Amber**: стилизация под янтарные ЭЛТ-мониторы (монохромный оранжевый).
2. **Шрифты**:
   - `4` — `Consolas` (размер 18 pt).
   - `5` — `Lucida Console` (размер 16 pt).
   - `6` — `Cascadia Code` (размер 18 pt, требуется наличие шрифта в системе).
3. **Курсор**:
   - `7` — Классическая нижняя полоса (`Small`, 25%).
   - `8` — Крупный прямоугольный блок (`Full`, 100%).
4. **Прозрачность**:
   - `9` — Регулировка непрозрачности окна в диапазоне от `30`% до `100`%.
5. **Сброс**:
   - `0` — Полный сброс параметров в стандартные фабричные значения Windows.
6. **Выход**:
   - `Q` — Завершение работы утилиты.

---

## Как проверить результат

Все параметры применяются к новым процессам. После применения выбранного пункта:

1. Откройте новое окно консоли: нажмите `Win + R`, введите `cmd` и нажмите `Enter`.
2. Если окно `cmd.exe` уже было открыто, закройте его и откройте заново.

---

## Возврат к стандартным настройкам

Вернуть исходный вид `cmd.exe` можно двумя способами:

1. **Через меню скрипта**: запустите `Customize-Cmd.ps1` и выберите пункт `0`.
2. **Вручную через PowerShell**:
   ```powershell
   # Удаление переопределений палитры и шрифтов в ветке по умолчанию
   Remove-ItemProperty -Path "HKCU:\Console" -Name "ColorTable*" -ErrorAction SilentlyContinue
   Set-ItemProperty -Path "HKCU:\Console" -Name "ScreenColors" -Value 0x07
   Set-ItemProperty -Path "HKCU:\Console" -Name "WindowAlpha" -Value 255
   ```
